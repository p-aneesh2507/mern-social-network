# MERN Social Network

## Overview
A full-stack social media application built using the MERN Stack where users can register, log in, create posts, like posts, comment, upload profile pictures, and interact with other users.

## Features
- User Authentication (JWT)
- Register & Login
- Create Posts
- Like & Comment
- Profile Management
- Image Upload
- Responsive UI
- MongoDB Atlas Database

## Tech Stack
Frontend:
- React
- CSS
- JavaScript

Backend:
- Node.js
- Express.js

Database:
- MongoDB Atlas

Authentication:
- JWT
- bcryptjs

Deployment:
- Frontend: Vercel
- Backend: Render

## Installation

### Clone Repository
git clone ...

### Backend
cd server
npm install
npm run dev

### Frontend
cd client
npm install
npm run dev
